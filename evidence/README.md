# .ye technical evidence

This directory is generated by the project monitoring service. It
contains public, reproducible Common Crawl capture references, deployed TLS
certificate observations, and an append-only infrastructure relationship graph.

Common Crawl rows retain the collection, WARC byte-range reference, public
content digest, hostname, and day-precision capture date. Exact collected URLs
remain in private operational state; a SHA-256 value permits verification of a
known URL without unnecessarily republishing paths or query strings.

TLS collection performs only a normal TLS handshake on TCP port 443. It does
not request web content. Certificate files are addressed by the SHA-256 digest
of their DER encoding. A failed connection is not published as proof that a
service is absent.

Graph edges link to observation classes. Shared infrastructure is a research
indicator and does not by itself establish ownership, affiliation, intent, or
wrongdoing.
