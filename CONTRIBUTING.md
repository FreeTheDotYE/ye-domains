# Contributing

Corrections and additional historical `.ye` names are welcome, but do not post personal registration data, private correspondence, credentials, or collector-identifying acquisition details in a public issue.

A proposed name should be valid under the public schema and should include enough evidence for the maintainers to review privately. Public accepted data contains only normalized domain-level facts. Source identities and acquisition timestamps are not published.

Before proposing a dataset change, run:

```sh
python scripts/validate_dataset.py
```

Technical relationships must be described as observations, not as proof of ownership, affiliation, intent, or wrongdoing.
